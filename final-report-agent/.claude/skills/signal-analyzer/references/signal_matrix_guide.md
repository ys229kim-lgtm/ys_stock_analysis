# 신호 매트릭스 추출 가이드

## 에이전트별 신호 추출 기준

### ① DART (재무 실적)

| 분석 항목 | 긍정(▲) 조건 | 중립(△) 조건 | 부정(▼) 조건 |
|---------|------------|------------|------------|
| 수익성 | 영업이익률 개선 YoY, ROE > 10% | 전년 수준 유지 | 이익률 하락, ROE < 5% |
| 성장 모멘텀 | 매출 CAGR 5y > 10%, 최근 YoY 가속 | CAGR 5~10%, 추세 유지 | CAGR < 5%, 감속 또는 역성장 |
| 리스크 | Red Flag 없음, FCF 증가 추세 | Red Flag 1개, FCF 보합 | Red Flag 2개+, FCF 2년 연속 감소 |
| 현재 가치 | - (DART는 주가 미포함) | - | - |

### ② Telegram (증권사 리포트)

| 분석 항목 | 긍정(▲) 조건 | 중립(△) 조건 | 부정(▼) 조건 |
|---------|------------|------------|------------|
| 수익성 | Buy 비율 > 70%, bullish theme에 이익 개선 언급 | Buy 50~70% | Buy < 50%, Sell 존재 |
| 성장 모멘텀 | TP 평균이 현재가 대비 20%↑, bullish theme에 성장 촉매 | TP 5~20%↑ | TP < 5%↑ 또는 하향 추세 |
| 리스크 | bearish theme 1개 이하 | bearish theme 2~3개 | bearish theme 4개+, 컨센 하향 |
| 현재 가치 | TP 평균 > 현재가 15%↑ | TP 5~15%↑ | TP < 현재가 또는 컨센 하향 |

### ③ News (뉴스 사건)

| 분析 항목 | 긍정(▲) 조건 | 중립(△) 조건 | 부정(▼) 조건 |
|---------|------------|------------|------------|
| 수익성 | 긍정 사건 수 > 부정 사건 수 × 2 | 비율 1~2배 | 부정 사건 수 > 긍정 |
| 성장 모멘텀 | 미래 계획 3개+, 신규 사업 발표 | 미래 계획 1~2개 | 미래 계획 없음, 사업 축소 |
| 리스크 | 진행 중 리스크 없음 | 진행 중 리스크 1~2개 | 진행 중 리스크 3개+, 소송/규제 |
| 현재 가치 | - | - | - |

### ④ Industry (산업 분석)

| 분析 항목 | 긍정(▲) 조건 | 중립(△) 조건 | 부정(▼) 조건 |
|---------|------------|------------|------------|
| 수익성 | 업사이클 진입, 수급 개선 | 사이클 중간, 보합 | 다운사이클, 공급 과잉 |
| 성장 모멘텀 | 단기 Base 성장률 10%+, Positive 확률 35%+ | 5~10% 성장 | < 5% 성장, Negative 확률 30%+ |
| 리스크 | 구조적 리스크 없음 | 경쟁 심화 우려 | 기술 파괴적 변화, 규제 리스크 |
| 현재 가치 | - | - | - |

### ⑤ Valuation (밸류에이션)

| 분析 항목 | 긍정(▲) 조건 | 중립(△) 조건 | 부정(▼) 조건 |
|---------|------------|------------|------------|
| 수익성 | 6종 방법 중 4개+ upside 양수 | 3개 upside 양수 | 2개 이하 upside 양수 |
| 성장 모멘텀 | 가중 평균 적정가 > 현재가 15%+ | 5~15%↑ | < 5%↑ |
| 리스크 | High 중요도 공시 없음 | High 공시 1개 | High 공시 2개+, 유상증자 공시 |
| 현재 가치 | upside_pct > 15% | upside_pct 5~15% | upside_pct < 5% 또는 음수 |

## 충돌 신호 원인 추론 유형

| 충돌 패턴 | 일반적 원인 |
|---------|-----------|
| DART ▼ vs Telegram ▲ | 증권사가 미래 실적 개선을 선반영; 현재 실적은 부진하나 Forward 기대치 높음 |
| News ▼ vs Valuation ▲ | 단기 부정 이벤트가 장기 밸류에이션에 아직 미반영; 또는 이벤트 영향 과대평가 |
| Industry ▲ vs DART ▼ | 산업은 호황이나 해당 기업의 경쟁력 약화 또는 실행 문제 |
| Telegram ▲ vs Valuation ▼ | 증권사 낙관론이 밸류에이션 계산 수치보다 높음; 가정 차이 확인 필요 |
| News ▲ vs Industry ▼ | 개별 기업 호재가 산업 전반 둔화와 무관하게 발생 |

## 공백 신호 처리 원칙

- Industry만 언급한 산업 구조 변화 → "Industry agent 단독 출처" 명시
- Telegram만 언급한 증권사 촉매 → "증권사 추정 단계" 명시
- Valuation 공시 이벤트만 존재 → "Valuation agent 단독 확인 사항" 명시
- 공백 신호는 높은 신뢰도로 결론에 반영하지 않되, 리포트에 언급은 가능

# signal-analyzer 스킬

## 목적
5개 에이전트 분석 방향이 일치하는지, 어디서 충돌하는지 파악하여 이후 섹션 작성의 뼈대를 잡는다.

## 입력
`normalized_summary.json` (Step 1 출력)

## 수행 절차 (LLM 직접 수행)

### 1단계: 신호 추출
각 에이전트에서 수익성·성장 모멘텀·리스크·현재 가치 방향을 추출.
추출 기준은 `references/signal_matrix_guide.md` 참조.

### 2단계: 정합성 매트릭스 작성
아래 형식으로 작성 (▲ 긍정 / △ 중립 / ▼ 부정 / - 해당없음):

```
                DART   Telegram   News   Industry   Valuation
수익성           ?       ?         ?       ?          ?
성장 모멘텀      ?       ?         ?       ?          ?
리스크           ?       ?         ?       ?          ?
현재 가치        -       ?         -       -          ?
```

### 3단계: 신호 분류

| 분류 | 기준 | 처리 방법 |
|------|------|---------|
| 정합 신호 | 3개 이상 에이전트가 같은 방향 | 높은 신뢰도로 결론에 반영 |
| 충돌 신호 | 에이전트 간 방향 불일치 | 원인 추론 후 양쪽 시각을 리포트에 병기 |
| 공백 신호 | 특정 에이전트에만 존재 | 단독 출처임을 명시 |

### 4단계: 종합 방향 판단
- **전반적 방향:** Bullish / Neutral / Bearish + 신뢰도
- **핵심 합의 영역:** 에이전트 대다수가 일치하는 포인트 3개 이내
- **핵심 충돌 영역:** 방향이 갈리는 포인트 + 원인 추론

## 출력 형식
아래 구조로 내부 메모 작성 (리포트 본문에 직접 삽입하지 않고, 섹션 작성 시 참조용으로 활용):

```
[신호 정합성 분석 결과]

정합성 매트릭스:
| 항목 | DART | Telegram | News | Industry | Valuation |
...

정합 신호 (신뢰도 높음):
- {항목}: {방향} — DART, News, Valuation 일치

충돌 신호 (양측 병기 필요):
- {항목}: DART ▲ vs. News ▼ — 원인: {추론}

공백 신호 (단독 출처):
- {항목}: Industry만 언급 — 리포트에 출처 명시

전반적 방향: {Bullish / Neutral / Bearish} (신뢰도: {높음/중간/낮음})
```

## 주의
- 충돌 신호를 LLM이 임의로 조정하거나 한쪽을 무시하지 않는다.
- 데이터 없는 에이전트는 `-` 처리하고 매트릭스에 명시한다.
- 에이전트 2개 이하 활성 시 분석 불가 → 에스컬레이션.

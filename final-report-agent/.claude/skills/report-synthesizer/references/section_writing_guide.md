# 섹션별 작성 가이드

## 공통 작성 원칙

- 독자 대상: 개인 투자자. WACC·EV/EBITDA·FCF 등 전문 금융 용어 별도 설명 없이 사용 가능
- 출처 표기 형식: `(← DART)` `(← Telegram)` `(← News)` `(← Industry)` `(← Valuation)`
- 에이전트 간 충돌: 양측 수치를 나란히 기술, 원인 추론 포함
- 데이터 없음: 해당 소섹션 말미에 "**[데이터 없음]** ○○ 에이전트 산출물 미포함" 명시

---

## 섹션 1: 기업 개요 및 데이터 커버리지

```
- 기업명, 업종, 상장 시장, 주요 사업 영역
- 분석 기준일 및 분석에 사용된 에이전트 목록
- 데이터 커버리지 현황 (누락 에이전트 및 해당 섹션 영향 명시)
```

**필수 포함:**
- 에이전트별 커버리지 표 (✓ 존재 / ✗ 누락)
- Industry agent 누락 시 → "시나리오 확률 기본값 적용 (Positive 30% / Base 50% / Negative 20%)" 명시

---

## 섹션 2: 비즈니스모델 분석

**참조 파일:** `biz_model_{날짜}_{기업명}.json` + `financials_{날짜}_{기업명}.json` 전체 재로드

### 2.1 수익 창출 구조
- **Price 축:** 주요 제품·서비스 단가 구조, 가격 결정력, 단가 추이
- **Quantity 축:** 핵심 볼륨 드라이버(판매량·구독자수 등), 볼륨 추이
- **Cost 축:** 원가 구조(COGS 비율), 고정비·변동비 구분, 영업 레버리지 수준

### 2.2 사업부문별 수익 기여도
- 부문별 매출·이익 비중 (← DART 세그먼트)
- 주력 부문 의존도 및 다각화 수준 평가

### 2.3 핵심 경쟁 우위 (Moat)
- Moat 유형: 전환비용 / 네트워크효과 / 원가우위 / 무형자산 / 효율적 규모
- 지속 가능성 평가 (강함/보통/약함)
- 경쟁사 대비 차별화 요소

### 2.4 비즈니스모델 강점·약점
- 뉴스·증권사 시각과 교차 확인하여 강화 또는 보완
- 비즈니스모델 리스크 (구조적 취약점)

---

## 섹션 3: 재무 실적 분석

**참조 파일:** `financials_{날짜}_{기업명}.json` 전체 재로드

### 3.1 수익성 추이 (최근 5~10년)
- 매출·영업이익·순이익 추이 및 이익률 변화
- 차트 이미지 파일 존재 시 인라인 삽입; 없으면 텍스트 표 + "(차트 미포함)" 명시

### 3.2 안정성 평가
- 부채비율·유동비율·이자보상배율
- Red Flag 항목 존재 시 **별도 강조 박스**로 표기

### 3.3 성장성 평가
- CAGR (3년·5년·10년), 최근 YoY
- 성장 모멘텀 가속·둔화 여부

### 3.4 현금흐름 분석
- 영업CF·FCF 추이, CAPEX 패턴
- FCF 창출 능력 종합 평가

### 3.5 실적 관련 주요 사건
- News agent 사건 타임라인에서 실적 영향 사건 발췌·연결
- News 데이터 없을 경우 소섹션 생략 + 데이터 없음 명시

---

## 섹션 4: 산업·시장 환경

**참조 파일:** `analysis_{날짜}_{기업명}.json` (industry 폴더) 전체 재로드

### 4.1 산업 내 포지션
- 밸류체인 위치, 경쟁 구도, 시장 점유율
- 대상 기업의 경쟁 우위·열위

### 4.2 단기 산업 환경 (1년)
- 수급 사이클 현재 위치
- 주요 수요·공급 변수
- 단기 산업 시나리오 확률 인용 (← Industry)

### 4.3 중기 산업 환경 (1~3년)
- 구조적 성장 동인 또는 리스크
- 기술 변화·규제 영향
- 중기 산업 시나리오 확률 인용 (← Industry)

### 4.4 뉴스 기반 산업 이슈 보완
- Industry agent가 커버 못한 최신 산업 이슈 (← News)
- News 데이터 없을 경우 소섹션 생략

---

## 섹션 5: 증권사 리포트·뉴스 종합

**참조 파일:** `analysis_{날짜}_{기업명}.json` (telegram 폴더) + `analysis_{날짜}_{기업명}.json` (news 폴더) 전체 재로드

### 5.1 증권가 컨센서스
- Buy/Hold/Sell 분포, 목표주가 범위 (← Telegram)
- 컨센서스 온도 변화 (최근 6개월 추이)
- 가장 낙관적 vs 가장 보수적 시각 비교

### 5.2 핵심 긍정 논거 (Bullish Points)
- 증권사 + 뉴스 긍정 사건 교차 확인
  - 증권가 언급 + 뉴스 확인 → **신뢰도 높음** 표시
  - 증권가만 언급 → **추정 단계** 표시

### 5.3 핵심 부정 논거 (Bearish Points)
- 증권사 + 뉴스 부정 사건 교차 확인
- 현재 진행 중인 리스크 이슈 **강조 표시**

### 5.4 미래 추진 계획 종합
- News agent 미래 계획 목록 + 증권사 촉매 예상 일정 통합
- 단기(6개월 이내)·중기(6개월~2년) 주요 일정

### 5.5 주요 공시 이벤트
- Valuation agent 공시 High 항목 발췌 (← Valuation)
- 투자 판단에 영향 있는 미완결 이벤트 강조

## Executive Summary 작성 원칙

**작성 시점:** 섹션 1~7 전체 완성 후 역순 작성 (결론을 먼저 쓰지 않기)

**구성 (1페이지 A4 기준):**

```
┌─────────────────────────────────────────────────────────────┐
│  {기업명} 기업분석 요약                      {분석일자}      │
│  현재 주가: {X}원 | 적정가: {Y}원 | upside: {Z}%            │
├─────────────────────────────────────────────────────────────┤
│ 비즈니스모델  │ 수익 구조 한 줄 요약, Moat 평가              │
│ 재무 실적     │ 최근 실적 방향성, Red Flag 여부              │
│ 산업 환경     │ 사이클 위치, 단기 방향성                     │
│ 증권가 시각   │ Buy X / Hold X / Sell X, 평균 TP {Y}원      │
│ 밸류에이션    │ 가중 평균 적정가 {Y}원, 현재 {고/저}평가     │
├─────────────────────────────────────────────────────────────┤
│ 핵심 투자 포인트                                             │
│  ① {긍정 포인트 1}                                          │
│  ② {긍정 포인트 2}                                          │
│  ③ {주의 리스크 1}                                          │
├─────────────────────────────────────────────────────────────┤
│ 시나리오 요약                                                │
│  Positive ({X}%): {한 줄 조건} → 주가 {범위}원              │
│  Base     ({Y}%): {한 줄 조건} → 주가 {범위}원              │
│  Negative ({Z}%): {한 줄 조건} → 주가 {범위}원              │
└─────────────────────────────────────────────────────────────┘
```

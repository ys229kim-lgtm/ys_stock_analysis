# 자기 검증 체크리스트

## 사용 방법
Step 6에서 아래 체크리스트를 순서대로 검토. 미통과 항목 발견 시 해당 섹션 재작성 1회.

---

## 필수 검증 항목

| # | 항목 | 기준 | 통과/실패 |
|---|------|------|---------|
| 1 | 7개 섹션 완성 | 섹션 1~7 모두 서술 존재 (데이터 없음 명시 포함) | |
| 2 | Executive Summary 존재 | 핵심 수치(현재가·적정가·upside·시나리오) 포함 | |
| 3 | 시나리오 확률 합산 | Positive + Base + Negative = 100% | |
| 4 | 주가 범위 근거 | Base·Negative는 fair_value_range 내, Positive 상단은 Telegram TP 최고치 이하 | |
| 5 | 고평가 케이스 처리 | 현재가 > fair_value_range.high 시 "모든 시나리오 하방 압력" 명시 여부 | |
| 6 | 수치 출처 | 모든 핵심 수치에 에이전트 출처 (← DART 등) 명시 | |
| 7 | 투자 권유 표현 | 아래 금지 표현 목록과 대조, 0건 | |
| 8 | 충돌 신호 처리 | 충돌 영역에 양측 시각 병기 (임의 조정 없음) | |
| 9 | 확률 보정 근거 | 각 시나리오 확률 옆에 보정량·출처 명시 | |
| 10 | 누락 에이전트 처리 | 누락된 에이전트 데이터를 사용한 섹션에 "데이터 없음" 명시 | |

## 금지 표현 목록

아래 표현 또는 유사한 표현이 리포트에 포함되면 즉시 삭제·수정.

### 직접 투자 권유
- "매수를 권유합니다"
- "투자를 추천합니다"
- "이 주식을 사세요"
- "지금이 매수 기회"
- "지금 사야 할 주식"
- "반드시 매수해야 합니다"

### 손실 위험 부정
- "손실 위험이 없습니다"
- "다운사이드 없음"
- "안전한 투자입니다"
- "원금 손실 걱정 없이"

### 수익 확신
- "확실한 수익"
- "반드시 오릅니다"
- "100% 상승합니다"
- "무조건 수익 납니다"

### 과도한 단언
- "이 주식은 반드시 {가격}원에 도달합니다"
- "틀림없이 {기간}까지 {가격}원이 됩니다"
- 특정 날짜에 주가가 정확히 얼마라는 단언 표현

---

## 허용 표현 (참고)

- "○○ 시나리오 기준 {가격} ~ {가격}원 범위 예상"
- "{지표}가 {조건}을 충족할 경우 Positive 시나리오 진입 가능성"
- "현재 밸류에이션 기준 {가격}원 대비 {X}% 상방/하방 여력"
- "증권사 평균 목표주가 {가격}원으로, 현재가 대비 {X}% 괴리"

---

## 재작성 기준

- **즉시 재작성**: 금지 표현 사용, 시나리오 확률 합≠100%, 주가 범위가 규칙 위반
- **보완 재작성**: 수치 출처 누락, 충돌 신호 병기 누락, 확률 보정 근거 없음
- 재작성 1회 후 동일 문제 지속 시 → 해당 항목에 "[수정 필요]" 태그 삽입 후 계속 진행

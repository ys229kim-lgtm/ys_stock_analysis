# Red Flag 참조 기준점 상세 정의

> 임계값은 **LLM 판단의 참조 기준점**입니다.
> 업종 특성을 반드시 감안하여 임계값 초과 ≠ 자동 Red Flag.

## 핵심 임계값

| 지표 | 위험 기준 | 심각 기준 | 업종 조정 |
|------|---------|---------|---------|
| 영업이익률 | 업종 맥락상 비정상 수준 | 3년 연속 하락 | 반드시 업종 평균 고려 |
| 이자보상배율 | 2.0 미만 | 1.0 미만 | 금융업 적용 불가 |
| 부채비율 | 200% 초과 | 300% 초과 | 반도체/중공업 고려 |
| FCF | 2년 연속 음수 | 3년 연속 음수 | 투자 사이클 고려 |
| 매출 성장률 | 2년 연속 역성장 | 3년 연속 역성장 | 산업 다운사이클 고려 |

## 업종별 주요 고려사항

### 반도체 (C261, C262)
- 부채비율 150~250%도 정상 (대규모 팹 설비투자)
- FCF 음수: 대규모 CAPEX 사이클 중 정상
- 이익률 변동성: 업황 사이클로 급등락 흔함

### 자동차 (C301, C302)
- 금융자회사 포함 시 부채비율 400%도 가능
- FCF: R&D·전동화 투자 증가로 일시 음수 허용

### 유통/소매 (G4, G5)
- 영업이익률 1~5%도 정상 (저마진 구조)

### 건설 (F)
- 부채비율 200~300% 정상 (공사계약 선수금 포함)

### 화학/소재 (C2)
- 업황 사이클로 이익률 변동 심함

## Red Flag 판단 절차 (LLM 가이드)
1. 임계값 초과 여부 확인
2. 업종 분류 및 특성 고려
3. 추세 방향성 확인 (개선 중 vs 악화 중)
4. 경쟁사 대비 상대적 위치 확인
5. 1~4 종합 후 Red Flag 최종 판단

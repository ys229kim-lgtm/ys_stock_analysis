# 차트 명세서

## 공통 스타일
- 라이브러리: matplotlib (Agg 백엔드, 정적 PNG)
- DPI: 150 / 배경: white
- 격자선: #E8E8E8, y축만 / 테두리: linewidth=1.5

| Operating Profit (영업이익) | #1E8449 |

| ROE | #8E44AD |
| ROA | #2980B9 |
| FCF | #16A085 |

## 레이블 규칙
- 영문/한글 병기: "Revenue (매출액)", "Operating Margin (영업이익률)"
- 수치: 조원 (1e12 나눔, 소수점 1자리) / %, 배수: 소수점 1자리

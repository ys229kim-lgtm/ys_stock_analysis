# 재무비율 계산식 정의

## 수익성
| 지표 | 계산식 | 단위 |
|------|--------|------|
| 영업이익률 (Operating Margin) | 영업이익 / 매출액 × 100 | % |
| 순이익률 (Net Margin) | 순이익 / 매출액 × 100 | % |
| ROE | 순이익 / 자본총계 × 100 | % |
| ROA | 순이익 / 자산총계 × 100 | % |

> ROE/ROA: 기말 단일값 기준 (기초/기말 평균 미적용 — 단순화)

## 안정성
| 지표 | 계산식 | 단위 |
|------|--------|------|
| 부채비율 (Debt Ratio) | 부채총계 / 자본총계 × 100 | % |
| 유동비율 (Current Ratio) | 유동자산 / 유동부채 × 100 | % |
| 이자보상배율 (Interest Coverage) | 영업이익 / 이자비용 | 배(x) |

## 현금흐름
| 지표 | 계산식 | 단위 |
|------|--------|------|
| FCF | 영업CF - CAPEX | 조원 |
| FCF 마진 | FCF / 매출액 × 100 | % |

> CAPEX = 유형자산의 취득 (투자CF 세부)

## 성장성
| 지표 | 계산식 |
|------|--------|
| YoY 성장률 | (당기 - 전기) / \|전기\| × 100 |
| CAGR (n년) | (최신값/n년전값)^(1/n) - 1 × 100 |

> 음수 기저값 YoY: 절댓값 분모 사용

# 할인율(Ke / WACC) 가이드 — 미국

## CAPM
```
Ke = Rf + Beta x ERP (+ 규모/특수 위험 프리미엄, 사용 시 근거 기재)
WACC = E/(D+E) x Ke + D/(D+E) x Kd x (1 - 세율)
```

| 요소 | 소스·기준 |
|------|-----------|
| Rf | **FRED DGS10 최신값**(macro_*.json) 또는 Treasury.gov. 날짜 표기. 매번 최신 적용 |
| ERP | 4.5~5.5% (기본 5.0%). 변동성·지정학 확대 국면이면 상단 사용 + 이유 기재 |
| Beta | 5Y 월간 베타(Yahoo/StockAnalysis 등), 소스 명시. 이상치(<0.5 또는 >2)면 업종 평균과 블렌딩 |
| Kd | 최근 발행 회사채 표면금리·YTM 또는 `이자비용/평균 차입금`(자본화 이자는 10-K 주석 확인) |
| 세율 | 실효세율(최근 TTM), 일시 요인 제외한 21~26% 범위 점검 |
| 부채 비중 | 시가 기준 E, 장부 D(리스 포함 여부 명시) |

## 가이드
- 금융(은행·보험)은 WACC가 아닌 **Ke**만 사용(RIM/DDM/P/B).
- 순현금 기업은 WACC ≈ Ke 로 단순화 가능(명시).
- 영구성장률 g: 1.5~3.0%, 명목 GDP 장기 성장 이하. WACC − g ≥ 2%p 유지(엔진도 미달 시 DCF 제외).
- 5년 FCF 성장률: 컨센서스 EPS CAGR 우선 → 없으면 과거 FCF/매출 성장 → 둘 다 없으면 DCF 비중 축소.
- 금리 환경이 급변한 시기(예: 10Y 5% 근처)에는 Rf 상승이 Ke에 직접 반영됨을 설명하고, 같은 기업의 **멀티플(P/B·P/E)이 압박받는 방향**임을 함께 서술.
- 이 가이드의 수치는 예시 범위이며 **최신 시장 데이터가 우선**한다.

## 기록 형식 (`assumptions.assumption_basis.ke`)
`"Rf 4.96% (FRED DGS10, 2026-10-22) + beta 1.34 (StockAnalysis 5Y) x ERP 5.0% = 11.7%"`

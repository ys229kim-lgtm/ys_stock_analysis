# 섹션 작성 가이드 (미국)

## 공통
- 독자: 개인 투자자(전문 용어 설명 불필요). 본문 한국어, 티커·재무 약어는 영문 유지.
- 출처 형식: `(← SEC 10-Q)`, `(← 8-K Ex.99.1)`, `(← StockAnalysis)`, `(← FRED)`, `(← Valuation)`, `(← 본 분석 산출)`. 에이전트 산출물 인용은 `(← Analyst)`, `(← News)`, `(← Industry)`.
- 충돌: 양측 수치를 나란히, 원인 추론 포함(예: 집계처별 목표가 평균 차이, XBRL vs 회사 발표 정의 차이).
- 데이터 없음: 소섹션 말미에 "**[데이터 없음]** ○○ 에이전트 산출물 미포함".
- 표지: `---` 블록으로 시작, 제목에 "기업분석 종합 리포트" 포함(docx 변환 스크립트가 이 문구를 기준으로 본문 시작점을 찾는다).
- 통화: `$` + 소수 2자리(주가), 금액은 `$X.XXB`/`$XM`.

## 섹션별 요구
### 1. 기업 개요 및 데이터 커버리지
기업·티커·거래소·업종(SIC)·규모·시가총액·회계연도 말 / 에이전트별 커버리지 표(✓/✗) / **데이터 한계** / **1.3 신호 정합성 요약**(매트릭스 + 정합·충돌·공백 신호 + 전반 방향)

### 2. 비즈니스모델
2.1 Price·Quantity·Cost / 2.2 세그먼트·지역 기여 / 2.3 Moat(강도 + 증거) / 2.4 강점·약점 교차 확인 표

### 3. 재무 실적
3.1 수익성 추이 표(5년 + 최근 분기) / 3.2 안정성(+Red Flag 박스) / 3.3 성장성 / 3.4 현금흐름·자본배분(환원 vs FCF) / 3.5 실적 관련 주요 사건 (분기 인용 시 회계연도 기준 월 범위 병기)

### 4. 산업·시장 환경
4.1 포지션·동종사 비교표 / 4.2 단기(1년) + 확률 / 4.3 중기(1~3년) + 확률 / 4.4 거시(금리·물가·고용·신용) 연계 + 발행일이 오래된 전망의 시점 불일치 병기

### 5. 애널리스트·뉴스 종합
5.1 컨센서스(등급·목표가 분포, 집계처 간 차이, 최근 변경 표) / 5.2 긍정 논거(애널리스트+뉴스 교차 → 신뢰도 표시) / 5.3 부정 논거 + **진행 중 리스크 강조 박스** / 5.4 향후 일정·촉매 / 5.5 SEC 공시 이벤트(high 항목, 원문 확인 여부 표기)

### 6. 밸류에이션
6.1 방법·가정 / 6.2 방법별 결과 표 + 가중 평균 검증식 / 6.3 방법 간 편차·컨센서스 괴리·독립성 한계·민감도 / 6.4 현재 주가 위치(저평가·적정 범위·고평가)

### 7. 투자 시나리오 및 주가 전망
`scenario_guide.md` 참조. 7.0 확률 산정(보정 표) → 7.1 시나리오 박스 3개 → 7.2 전환 신호 → 7.3 핵심 포인트

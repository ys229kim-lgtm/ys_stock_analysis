# 투자 시나리오 및 주가 전망 가이드

## 구성 원칙
1. Positive / Base / Negative 각각에 **재무·산업(거시)·촉매·공시** 4축 전제를 쓰고 출처를 붙인다.
2. 확률 = 앵커(industry `scenario_probs.short`, 없으면 30/50/20) ± 신호 보정. 보정은 `build_scenarios.py` 입력(`adjustments.json`)으로 관리하며 합계 0, 시나리오별 ±15%p 이내.
3. 주가 범위는 스크립트 출력(`scenarios.json`)을 그대로 쓴다. 본문 수치는 `$XX.XX` 소수 2자리로 scenarios.json 값과 일치해야 한다(validate_report가 검사).

## 보정 규칙 (Positive 방향 기준)
| 신호 | 보정 |
|------|------|
| 재무: FCF·마진 회복 신호 | +2~3%p |
| 재무: Red Flag 현실화 | −2~3%p (감소분은 Negative로) |
| 애널리스트: Buy 우세/상향 흐름 | +1~2%p |
| 애널리스트: 컨센서스 목표가 하향 흐름 | −2~3%p |
| 뉴스·거시: 진행 중 리스크 3건 이상 | −3~5%p |
| 밸류에이션: 고평가 | −2~3%p |
| 밸류에이션: 저평가 15%+ | +2~3%p |
| (추가 판단) 위 표에 없는 근거 | 별도 표기, 근거 명시 |
- 감소분/증가분을 어느 시나리오로 보낼지(Base/Negative) 근거와 함께 `adjustments.json`에 기록.

## 주가 범위 규칙 (build_scenarios.py가 강제)
| 시나리오 | 하단 | 상단 |
|----------|------|------|
| Positive | 적정 범위 상단 | 애널리스트 최고 TP |
| Base | 적정 범위 하단 | 적정 범위 상단 |
| Negative | negative_floor(합리적 하방, 근거 필수) | 적정 범위 하단 |
- negative_floor 후보: 애널리스트 최저 TP, 52주 저가, 보수적 P/B 하단 등. 선택 근거를 `--negative-basis`에 기록.
- 현재가 > 적정 범위 상단: "현재 주가 고평가 구간 — 모든 시나리오에서 하방 압력" 명시.
- 애널리스트 TP가 현재가보다 모두 높거나 낮아 하방/상방 시나리오 근거가 한쪽에 치우치면 그 한계를 서술.

## 시나리오 박스 형식
```
[전제 조건]
 - 재무: ...                 ← SEC / 실적 발표
 - 산업·거시: ...            ← Industry / FRED
 - 촉매: ...                 ← News / Analyst
 - 공시: ...                 ← SEC 8-K 등
[예상 실적]  매출 / EPS / 마진 범위
[주가 전망]  $XX.XX ~ $YY.YY (현재가 대비 +A% ~ +B%)
[핵심 모니터링] 이 시나리오 진행/이탈을 확인하는 선행 지표
```
- 확률 가중 참고값(`probability_weighted_reference`)은 "예측치가 아닌 참고 수치"로 표기하고 산식(구간 중간값 × 확률)을 밝힌다.

## 7.2 전환 신호 / 7.3 핵심 포인트
- Base→Positive, Positive→Base, Base→Negative, Negative→Base 각각 **관측 가능한 지표 + 임계값**(예: 30년 모기지 7% 하회).
- 기회 요인 1~3, 리스크 1~3, 향후 3~6개월 확인 이벤트(시점 포함; 추정이면 "추정").

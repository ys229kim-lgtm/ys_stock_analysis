# 신호 정합성 분석 가이드

## 목적
5개 영역의 방향이 일치하는지, 어디서 충돌하는지 파악해 섹션 작성의 뼈대로 쓴다. 결과는 리포트 1.3에 요약한다.

## 매트릭스 (▲ 긍정 / △ 중립 / ▼ 부정 / - 해당 없음)
| 항목 | 재무(SEC) | 애널리스트 | 뉴스·매크로 | 산업 | 밸류에이션 |
|------|-----------|-----------|-------------|------|------------|
| 수익성 | 마진 추세 | 추정치 개정 방향 | 실적 사건 | 업황 | 정상화 이익 대비 |
| 성장 모멘텀 | 매출·주문·백로그 | 컨센서스 성장 | 가이던스·촉매 | 수요 사이클 | 가정된 성장 |
| 리스크 | 레버리지·FCF·Red Flag | 목표가 하향·하방 의견 | 진행 중 리스크 | 거시·규제 | 하방 완충(P/B 등) |
| 현재 가치 | - | 평균 TP 대비 | - | - | 적정 범위 내 위치 |

## 분류
| 분류 | 기준 | 처리 |
|------|------|------|
| 정합 신호 | 3개 이상 영역이 같은 방향 | 높은 신뢰도로 결론에 반영 |
| 충돌 신호 | 방향 불일치 | 원인 추론 + 양측 시각 병기, 임의 조정 금지 |
| 공백 신호 | 한 영역에만 존재 | 단독 출처임을 명시 |

## 흔한 충돌 패턴 (미국)
- **전분기 대비 개선 vs 전년 대비 악화**(마진, 주문): 둘 다 서술하고 가이던스 방향을 근거로 비중 판단.
- **P/B 할인 vs P/E 중립**: ROE가 자본비용 미만이면 순자산 할인은 정당화될 수 있음 — 자동 저평가로 해석하지 않음.
- **컨센서스 목표가 vs 모델 적정가 괴리**: 입력(Forward vs TTM EPS, 멀티플, 할인율) 차이를 분해해 설명. 목표가에는 12개월 시점 효과와 낙관 편향 가능성.
- **집계처 간 수치 차이**: 값을 모두 병기하고 사용한 값을 명시.

## 종합 방향
Bullish / Neutral / Bearish + 신뢰도(높음·중간·낮음). 에이전트 2개 이하 활성 시 분석 불가 → 에스컬레이션.

# 자기 검증 체크리스트 (validate_report.py 자동 + 수동 보완)

## 자동 검사 (validate_report.py)
1. 섹션 1~7 및 Executive Summary 존재
2. 확률 합 100%, Positive/Base/Negative 확률이 본문에 표기됨 (scenarios.json 일치)
3. 시나리오별 가격 범위(`$XX.XX`)가 본문에 표기됨
4. 금지 표현 0건
5. 출처 표기(←) 20회 이상
6. 현재가 > 적정 범위 상단일 때 "모든 시나리오에서 하방 압력" 문구
7. 면책 문구

## 수동 검사 (에이전트가 직접 확인)
- 수치 충돌 병기 여부(집계처 차이, XBRL vs 발표 값)
- 확률 보정마다 근거·보정량 표기, '추가 판단' 표시
- 누락 에이전트를 쓰는 섹션에 "데이터 없음" 명시
- 읽지 않은 원문(스니펫만 본 기사, 미확인 공시)을 사실처럼 쓰지 않았는지
- 회계연도·분기 표기(예: 3Q26 = 2026-06~08) 정확성
- 발행 시점이 오래된 전망 인용 시 시점 불일치 표기
- 단위(USD millions vs billions) 혼용 없음

## 금지 표현
### 직접 투자 권유
"매수를 권유합니다", "투자를 추천합니다", "이 주식을 사세요", "지금이 매수 기회", "지금 사야 할 주식", "반드시 매수해야 합니다"
### 손실 위험 부정
"손실 위험이 없습니다", "다운사이드 없음", "안전한 투자입니다", "원금 손실 걱정 없이"
### 수익 확신
"확실한 수익", "반드시 오릅니다", "100% 상승합니다", "무조건 수익 납니다"
### 과도한 단언
"이 주식은 반드시 {가격}원/달러에 도달합니다", "틀림없이 {기간}까지 …", 특정 날짜 주가의 정확한 단언

## 허용 표현
"○○ 시나리오 기준 $A ~ $B 범위 예상", "{지표}가 {조건}을 충족할 경우 Positive 시나리오 진입 가능성", "현재 밸류에이션 기준 $X 대비 {Y}% 상방/하방 여력", "평균 목표주가 $X로 현재가 대비 {Y}% 괴리"

## 재작성 기준
- 즉시: 금지 표현, 확률 합≠100%, 가격 범위 규칙 위반
- 보완: 출처 누락, 충돌 병기 누락, 보정 근거 누락
- 1회 재작성 후에도 실패 시 해당 위치에 `[수정 필요]` 태그를 남기고 사용자에게 보고

# 미국 상장사 재무 분석 프레임워크

## 공통 원칙
- 단위: USD millions. 주당 값 USD. 회계연도(FY)는 회사별 결산월이 다르므로 `fy_end` 날짜를 항상 병기 (KBH: 11월 말, 따라서 "3Q26" = 2026-06~08).
- GAAP 우선, 비GAAP(조정 EPS, 조정 총마진, EBITDA)는 별도 표기 + 조정 항목 기재.
- 모든 수치에 출처: `← SEC 10-K`, `← SEC 10-Q`, `← 8-K Ex.99.1`, `← IR 보도자료`.
- 한국 기준과 달리 **자사주 매입이 주당 지표를 좌우**: 주식수 변화율(YoY)과 환원 vs FCF를 반드시 본다.

## 1. 수익성
| 지표 | 산식 | 주의 |
|------|------|------|
| 총마진 | 총이익/매출 | 업종별 정의 상이(홈빌더: 주택 총마진, 자본화 이자 상각 포함) |
| 영업마진 | 영업이익/매출 | XBRL `OperatingIncomeLoss` 없으면 실적 발표자료 사용 |
| 순이익률 | 순이익/매출 | 일회성(세금, 평가손익) 분리 |
| ROE | 순이익/평균 자기자본 | 자사주 매입으로 자기자본 축소 시 ROE 상승 착시 |
| ROIC | NOPAT/(차입+자기자본-현금) | 보유현금·재고 큰 업종은 분모 정의 명시 |
- 최근 8분기 흐름 + 전년 동기 대비, 전분기 대비를 **둘 다** 제시(충돌 시 병기).
- 영업 레버리지: 매출 변화율 대비 영업이익 변화율.

## 2. 안정성
- 부채/자본, 순차입/순자본 = (차입-현금)/((차입-현금)+자기자본)
- 유동성: 현금 + 미사용 신용한도(10-Q "Liquidity"), 만기 구조(10-K 부채 주석)
- 이자보상배율: 이자가 자본화되는 업종(홈빌더·건설)은 비교 불가 → 별도 설명
- Altman Z, Piotroski F 는 집계 사이트 값을 쓸 경우 출처 명시
- **Red Flag 기준**: 영업마진 3년 연속 하락, 순차입/순자본 급증(>10%p/년), 감사의견·재작성(8-K 4.02), 계속기업 불확실성 문구, 영업CF 3년 연속 순이익 미달

## 3. 성장성
- 매출 CAGR 3·5·10년, 최근 YoY, TTM 대비 FY
- EPS 성장: 주식수 감소 기여분을 분리 (순이익 성장률 vs EPS 성장률)
- 컨센서스(FY1/FY2) 대비 가이던스 비교는 analyst agent 산출물 참조

## 4. 현금흐름·자본배분
- FCF = 영업CF − CAPEX (재고 투자형 업종은 영업CF가 변동 큼 → 3년 평균 병기)
- 환원 합계 = 배당 + 자사주 매입. **환원/FCF**, 환원/순이익
- 자사주 매입 단가 vs 현재 주가, 잔여 승인 한도 (10-Q Part II Item 2)
- 순차입 증가가 환원 재원인지 확인

## 5. 세그먼트·지역
- 10-K/10-Q 세그먼트 주석 또는 실적 발표 보충표. 권역별 매출·이익·재고·수주 등.
- 의존도(최대 세그먼트 비중), 성장 격차.

## 6. 종합 평가 출력 구조
강점 / 약점 / Red Flag(없으면 "해당 없음" + 점검 기준 명시) / 핵심 모니터링 지표 3~5개

## 홈빌더 특이사항 (SIC 1531 등)
- 핵심 지표: 인도(deliveries), 순주문, 수주잔고(수량·금액), ASP, 주택 총마진(조정 포함), SG&A 비율, 인도 전환율, 커뮤니티 수, 보유·통제 부지
- 재고(Inventories)가 자산의 대부분 → 영업CF는 재고 증감에 지배
- 순주문 → 수주잔고 → 인도 → 매출 순으로 선행성 확인

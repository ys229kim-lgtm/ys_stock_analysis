# 산업 시나리오 확률 가이드 (미국)

## 원칙
- 단기(1년)·중기(1~3년) 각각 Positive / Base / Negative, 합 100%.
- 기본 앵커 30 / 50 / 20에서 출발해 **근거가 있는 만큼만** 이동(각 시나리오 ±15%p 이내). 근거 없는 극단 확률(예: 70% 이상) 금지.
- 확률마다 조건(무엇이 일어나면 그 시나리오인가)과 정량 범위(매출·이익·시장 성장률)를 적는다.
- 단기와 중기가 같은 확률이어도 괜찮으나, 방향이 다르면 이유를 적는다.

## 거시 변수 → 업종 민감도 체크
| 변수 | 영향이 큰 업종 | 확인 지표 |
|------|---------------|-----------|
| 금리(10Y, 모기지) | 홈빌더, 리츠, 유틸리티, 성장주 멀티플, 은행 NIM | DGS10, MORTGAGE30US, 연준 경로 |
| 물가(CPI) | 소비재 원가·가격 결정력, 임금 | CPIAUCSL YoY |
| 고용·소비 | 소비재, 소매 | UNRATE, UMCSENT, 소매판매 |
| 신용 스프레드 | 하이일드 의존 기업, 은행 | BAMLH0A0HYM2 |
| 달러·관세 | 수출·글로벌 매출 비중 높은 기업 | DXY, 관세 뉴스 |
| 유가 | 에너지, 운송, 화학 | DCOILWTICO |

## 시나리오 정의 템플릿
- Positive: 거시 개선(금리 하락 등) + 업종 수요 회복 + 회사 고유 촉매. 조건 3개 이상 명시.
- Base: 현 추세 유지. 가이던스·컨센서스 범위 내.
- Negative: 거시 악화 또는 수요 충격, 원가·규제 부담. 조건 3개 이상 명시.

## 근거 표기
- 거시 수치는 `← FRED`, `← Freddie Mac`, 전망은 `← {기관} {발행월}`.
- 발행 시점이 6개월 이상 지난 전망은 "시점 불일치"로 표시하고 가중을 낮춘다.

# 리포트 생성 스킬 (report-builder)

## 목적
폴더 생성, JSON 검증, 마크다운·Word 리포트 생성을 수행한다.

## 트리거
- 폴더 생성: Step 0 완료 직후 (`setup_dirs.py`)
- JSON 검증: Step 4 완료 후 (`validate_analysis.py`)
- 리포트 생성: 검증 통과 후 (`generate_md.py`, `generate_docx.py`)

## 스크립트 목록

| 스크립트 | 실행 시점 | 역할 |
|----------|----------|------|
| `setup_dirs.py` | Step 0 후 | 출력 폴더 3개 생성 |
| `validate_analysis.py` | Step 4 후 | JSON 구조 체크리스트 자동 검증 |
| `generate_md.py` | 검증 통과 후 | 마크다운 리포트 생성 |
| `generate_docx.py` | md 생성 후 | python-docx 기반 Word 리포트 생성 |

## 리포트 문서 구조

```
표지 (기업명, 분석 산업명, 분석일자, 데이터 소스 요약)
목차
1. 산업 개요 및 밸류체인
2. 시장 규모 및 성장률 전망
3. 주요 플레이어 경쟁 구도
4. 수요·공급 사이클 분석
5. 글로벌 트렌드 및 기술 변화
6. 규제 환경
7. 단기(1년) 확률적 방향성 전망
8. 중기(1~3년) 확률적 방향성 전망
9. 종합 평가 및 대상 기업 시사점
부록: 참고 자료 목록
```

## 복수 산업 처리

- **md**: 산업별 독립 파일 (`report_{날짜}_{기업명}_{산업명}.md`)
- **docx**: 하나의 통합 파일 (산업 A 섹션 → 산업 B 섹션 순서로 이어서 기술)

## docx 시각화 규칙 (python-docx)

- 확률 시나리오 표: Positive 셀 배경 `#DDEEFF` / Base 셀 `#F0F0F0` / Negative 셀 `#FFDDDD`
- 밸류체인: 단계별 테이블 (→ 화살표로 흐름 표현)
- 표지: 기업명 H1, 산업명 H2, 날짜·데이터 소스 소자

## 영역별 심화 분석 기준

### 영역 1: 산업 개요 및 밸류체인

**밸류체인 작성 원칙:**
- 최소 4단계, 최대 7단계로 구성
- 각 단계에 실제 기업명 포함 (이름 없는 '제조업체' 등 금지)
- 대상 기업이 어느 단계에 속하는지 명시

**핵심 경쟁 요소 판단 기준:**
- 가격 경쟁: 원가 구조, 규모의 경제 중요
- 기술 경쟁: IP, R&D 투자, 선단 공정 중요
- 속도 경쟁: 납기, 재고 관리, SCM 중요
- 관계 경쟁: 고객 락인, 인증, 선점 중요

---

### 영역 2: 시장 규모

**수치 출처 우선순위:**
1. 텔레그램 리포트 내 기관 인용 (Gartner, IDC, IHS 등)
2. 웹 검색 결과의 글로벌 리서치 기관 보고서
3. 증권사 리포트 내 시장 규모 추정치
4. LLM 추론 (반드시 "추정" 명기)

---

### 영역 3: 경쟁 구도

**경쟁 강도 평가 (High/Medium/Low):**

| 등급 | 기준 |
|------|------|
| High | 1위 업체 점유율 < 40%, 가격 경쟁 심화, 신규 진입자 증가 |
| Medium | 1위 점유율 40~60%, 과점 형태, 기술 차별화 존재 |
| Low | 1위 점유율 > 60%, 진입장벽 높음, 독과점 구조 |

**Porter 5 Forces 간략 적용:**
- 공급자 협상력: 원재료 공급업체 집중도
- 구매자 협상력: 고객사 집중도, 대체 가능성
- 대체재 위협: 기술 대체 가능성
- 신규 진입 위협: 자본/기술 진입장벽
- 기존 경쟁자: 현재 경쟁 강도

---

### 영역 4: 수급 사이클

**사이클 위치 판단 지표 (3가지 모두 확인):**

1. **제품 가격 QoQ 추이** (최근 2~3분기)
   - +10% 이상 연속: 호황 신호
   - 0~±5%: 안정 또는 보합
   - -10% 이하 연속: 하락/바닥 신호

2. **재고/출하 비율**
   - 비율 상승(재고 > 출하): 공급 과잉 → 하락
   - 비율 하락(출하 > 재고): 수요 증가 → 회복/호황

3. **텔레그램 리포트 언어 시그널**
   - '바닥', '저점', '턴어라운드': 바닥 → 회복
   - '회복세', '상승 전환': 회복 중
   - '호황', '슈퍼사이클': 호황
   - '조정', '과잉공급': 하락

**판단 매트릭스:**
```
가격 상승 + 재고 감소 + 긍정 언어 → 회복 중 또는 호황
가격 하락 + 재고 증가 + 부정 언어 → 하락 또는 바닥
신호 혼재                           → LLM 종합 판단 + 불확실성 명시
```

---

### 영역 5: 글로벌 트렌드

**트렌드 선별 기준:**
- 향후 3년 이내 산업에 10% 이상 영향을 미칠 변화만 포함
- 구체적인 기술명 또는 정책명 사용 (추상적 표현 금지)
- 지정학적 요인 필수 포함 (미중 갈등, 공급망 재편)

---

### 영역 6: 규제 환경

**규제 방향성 판단:**
- 강화: 기업 비용 증가, 진입장벽 효과 가능
- 완화: 시장 확대, 신규 플레이어 진입 가능성
- 불확실: 정책 방향 미확정, 선거·정권교체 변수

---

### 영역 9: 종합 평가 (3가지 핵심 질문)

**① 시장 순풍 vs 역풍**
- 산업 CAGR > 기업 매출 성장률 목표: 순풍
- 산업 CAGR < 기업 성장률 목표: 역풍 (기업이 시장보다 빨리 성장해야 함)
- 구조적 수축 산업 + 기업의 핵심 매출: 강한 역풍

**② 포지셔닝 개선 여지**
- 점유율 트렌드 (상승/유지/하락) 기술
- 기술력 갭 (선두 대비 대상 기업의 거리)
- 비용 구조 (업계 평균 대비 원가율)

**③ 할인율·멀티플 연결**
```
예시:
- 반도체 산업 CAGR 10~15% → 사이클 피크 PER 20~25x 적용 가능
- 성숙 산업 CAGR 2~5% → 배당 중심, 낮은 멀티플 (PER 8~12x)
- 고성장 산업 CAGR 20%+ → 높은 멀티플 (PER 40~60x) 또는 EV/Revenue 기준
```

# 확률 시나리오 산출 기준

## 원칙

1. **데이터 충분 시** (텔레그램 리포트 3건 이상, 일관된 시각)
   - 형식: `"35%"`
   - 의무: `source` 필드에 근거 명시 (`"텔레그램 리포트 A + 웹 검색"`)

2. **데이터 부족 시** (리포트 2건 이하)
   - 형식: `"35% (데이터 부족 추정값)"`
   - LLM 추론 허용하되 레이블 의무화

3. **리포트 강세·약세 충돌 시**
   - 형식: `"30~45%"`
   - 두 시각 요약을 conditions에 별도 기재

4. **3개 시나리오 합계 = 100%** (±1% 허용)
   - 범위 표기 시 중간값으로 계산하여 검증

---

## 확률 배분 가이드라인

### 강한 방향성이 있는 경우 (텔레그램 리포트 7건 이상, 80%+ 일치)
```
Positive: 45~55%
Base:     30~40%
Negative: 10~20%
(또는 반대 방향으로 역전)
```

### 방향성 불명확 (리포트 혼재, 데이터 중립)
```
Positive: 25~35%
Base:     40~50%
Negative: 20~30%
```

### 리스크 집중 환경 (규제·지정학·과잉공급 우려 강함)
```
Positive: 15~25%
Base:     35~45%
Negative: 30~45%
```

---

## 시나리오 구분 기준

### Positive (긍정 시나리오)
- 현재 가장 기대되는 상승 요인이 2~3개 이상 동시 실현
- 업사이드 케이스: 시장 컨센서스를 상회하는 성장

### Base Case (기본 시나리오)
- 현재 추세가 유지되거나 컨센서스 수준에서 실현
- 가장 높은 확률을 부여하는 것이 일반적

### Negative (부정 시나리오)
- 주요 리스크 요인이 현실화
- 블랙스완은 포함하지 않음 (확률 < 5% 수준 제외)

---

## 단기·중기 방향성 일치 여부

분석 완료 후 반드시 기술:
```json
"direction_consistency": "단기·중기 방향성 일치 (회복→성장 트랙), 변곡점: {시기 및 조건}"
```

**불일치 예시:** 단기 부정(재고 조정) → 중기 긍정(구조적 수요 증가)
→ `"단기 역풍 후 중기 반전 예상, 변곡점: 2026년 하반기 재고 정상화"`

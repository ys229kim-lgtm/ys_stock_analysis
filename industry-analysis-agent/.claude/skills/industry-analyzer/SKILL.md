# 산업 분석 스킬 (industry-analyzer)

## 목적
수집된 텔레그램 리포트와 웹 데이터를 교차 분석하여 7대 영역 구조화 분석 + 확률적 시나리오를 도출한다.

## 트리거
Step 2(텍스트 추출) + Step 3(웹 수집) 모두 완료 후 (Step 4)

## 분석 프레임워크

### 7대 영역 분석 지침

#### 1. 산업 개요 및 밸류체인
- 산업 정의 및 범위 (어디서 어디까지)
- 밸류체인 단계별 구조 (원재료 → 부품 → 제조 → 유통 → 최종 소비)
- 각 단계별 주요 플레이어
- **대상 기업의 밸류체인 내 위치 명시** (필수)
- 산업 내 핵심 경쟁 요소 (가격/기술/납기 등)

#### 2. 시장 규모 및 성장률 전망
- 현재 글로벌 시장 규모 (출처 명시)
- 국내 시장 규모 (가능 시)
- 단기(1년) 예상 시장 규모 및 성장률
- 중기(3년) 예상 시장 규모 및 CAGR 범위
- 성장 동인 Top 3

#### 3. 주요 플레이어 경쟁 구도
- 글로벌 Top 5 기업 및 시장점유율
- 국내 주요 플레이어
- **대상 기업의 포지션 및 경쟁 우위/열위** (필수)
- 경쟁 강도 평가 (High/Medium/Low + 근거)

#### 4. 수요·공급 사이클 분석

**판단 기준 (아래 3가지를 종합하여 LLM이 최종 판단):**
1. 제품 가격 추이 (전분기 대비 QoQ %, 최근 2~3분기)
2. 산업 재고/출하 비율
3. 텔레그램 리포트의 언어적 시그널 ('바닥', '회복', '상승 전환' 등)

출력:
- 현재 사이클 위치: 호황 / 하락 / 바닥 / 회복 중
- 재고 수준 및 추이
- 단기(1년) 사이클 반전 가능성 및 예상 시점
- 중기(1~3년) 사이클 방향성

#### 5. 글로벌 트렌드 및 기술 변화
- 산업 패러다임 변화 요인 (AI, ESG, 탈탄소 등)
- 게임체인저 기술 및 도입 속도
- 지정학적 요인 (공급망 재편, 미중 갈등 등)

#### 6. 규제 환경
- 국내 규제·정책 지원 현황
- 해외 주요 규제 (미국·EU·중국)
- 단기(1년) 예상 규제 변화 및 영향
- 중기(1~3년) 규제 방향성 (강화/완화/불확실)

#### 7. 확률적 방향성 전망

**단기(1년 이내)와 중기(1~3년) 각각 3개 시나리오:**

```json
{
  "horizon": "1년 이내",
  "positive": {
    "probability": "35%",
    "conditions": ["조건1", "조건2", "조건3"],
    "market_growth_est": "+15~20%",
    "impact_on_target": "대상 기업 영향 한 줄 요약",
    "source": "텔레그램 리포트 A + 웹 검색"
  },
  "base": { ... },
  "negative": { ... }
}
```

**확률 합계 = 100% 반드시 유지**

### 종합 평가 및 대상 기업 시사점 (섹션 9)

반드시 아래 3가지 핵심 질문에 답한다:

**① 시장 순풍 vs 역풍**
- 이 산업이 대상 기업에 구조적 성장 기회를 제공하는가?
- 산업 성장률 vs 기업 성장률 비교

**② 포지셔닝 개선 여지**
- 현재 점유율·기술력·비용 구조가 산업 성장에 버티고 있는가?
- 개선 여지 또는 위협 요인 구체화

**③ 할인율·멀티플 연결**
- 이 산업의 CAGR 전망이 DCF 성장률 가정 또는 업종 PER 밴드에 어떻게 연결되는가?
- 가치평가 시 활용 가능한 산업 CAGR 범위 제시

---

## 확률 산출 원칙

| 상황 | 처리 |
|------|------|
| 데이터 충분 (리포트 3건+, 일관된 시각) | `"35%"` 형식, "~을 근거로 추정" 명시 |
| 데이터 부족 (리포트 2건 이하) | `"35% (데이터 부족 추정값)"` 레이블 의무 |
| 리포트 강세·약세 충돌 | `"30~45%"` 범위 표기 + 두 시각 요약 |
| 3개 합계 ≠ 100% | 허용 불가, 반드시 재조정 |

## 밸류에이션 영향 분류

### POSITIVE (상향 조정 요인)
- 대규모 자사주 매입/소각 → EPS 상승
- 고마진 사업 양수 → EBITDA 개선
- 대형 장기 계약 체결 → FCF 성장률 상향
- 배당 증대 → DDM 적정가 상승

### NEGATIVE (하향 조정 요인)
- 유상증자 (주가 희석) → EPS↓, 주주가치 분산
- 대규모 소송 패소/합의 → 현금 유출
- 핵심 사업 양도 → EBITDA 감소
- 최대주주 변경 → 경영 불확실성

### NEUTRAL
- 무상증자 (순자산 불변)
- 임원 일부 교체 (전략 연속성 유지)
- 정기공시 일정 발표

## 진행 중 이슈 판단 기준

다음 조건 충족 시 ongoing_issues에 별도 기록:
1. 공시 status = "진행중" 또는 결론 미확정
2. 소송/분쟁에서 최종 판결 미완료
3. 계약 체결 발표 후 실행 완료 전
4. 유상증자 결정 후 납입 전

## 향후 일정 식별 기준

공시 본문에서 아래 표현 발견 시 upcoming_schedule에 추가:
- "~예정", "~에 완료 예정", "~까지 납입"
- 결산 발표 예정일, 주주총회 예정일
- 전환사채 만기일, 콜옵션 행사 가능 일자

# WACC 계산 가이드

## 기본 수식

```
WACC = Ke × (E/V) + Kd × (1 - t) × (D/V)

Ke = Rf + β × ERP     (CAPM)
Kd = 평균 차입금리    (없으면 Rf + 스프레드)

E = 시가총액
D = 순차입금
V = E + D
t = 유효 법인세율
```

## 단순화 버전 (부채 구조 미확인 시)

```
WACC ≈ Ke = Rf + β × ERP
```

부채비율 < 30% 또는 순부채 < 0 (순현금 상태) 시 단순화 허용.

---

## 각 파라미터 수집 방법

### 1. 무위험수익률 (Rf)
- **수집:** 한국은행 경제통계시스템 또는 KoFiaBond
- **기준:** 국고채 3년 만기 수익률 (최신 주간 평균)
- **쿼리:** `"국고채 3년 수익률" site:bok.or.kr`
- **범위 안내:** 2024~2025년 기준 약 3.0~3.7%

### 2. 시장위험프리미엄 (ERP)
- **기본값:** 5.5% (KOSPI 역사적 초과수익률 평균)
- **수집:** 학술/기관 자료 또는 Damodaran 국가 ERP 테이블 참조
- **보수적 시나리오:** 6.0%
- **낙관적 시나리오:** 5.0%

### 3. 베타 (β)
- **1순위:** 네이버 금융 또는 한국거래소 제공 52주 베타
- **2순위:** Bloomberg/FnGuide 데이터
- **3순위:** 업종 평균 베타 (아래 기본값 참고)
- **쿼리:** `"{종목코드} 베타" OR "{기업명} beta 52주"`

| 업종 | 기본 베타 |
|------|---------|
| 반도체 | 1.20~1.50 |
| 자동차 | 0.90~1.20 |
| 은행/금융 | 0.80~1.10 |
| IT서비스/소프트웨어 | 1.00~1.30 |
| 바이오/제약 | 1.10~1.60 |
| 유틸리티 | 0.40~0.70 |
| 소비재/유통 | 0.70~1.00 |
| 에너지/화학 | 0.90~1.20 |

### 4. 부채 비용 (Kd)
- **수집:** 사업보고서 재무주석 "차입금 현황" 표
- **없으면:** Rf + 신용 스프레드 (0.5~1.5% 가정)

## WACC 계산 예시

| 파라미터 | 값 | 출처 |
|---------|---|------|
| Rf | 3.4% | 국고채 3년 (2025-06-09) |
| β | 1.25 | 네이버 금융 52주 베타 |
| ERP | 5.5% | KOSPI 역사적 ERP 기본값 |
| **Ke** | **10.3%** | 3.4% + 1.25 × 5.5% |
| Kd | 4.5% | 사업보고서 차입금 가중평균 |
| t | 22% | 최근 3개년 평균 유효세율 |
| E/V | 75% | 시가총액 / (시가총액+순차입금) |
| D/V | 25% | |
| **WACC** | **8.6%** | 10.3%×0.75 + 4.5%×0.78×0.25 |

---

## 재현성 원칙

**WACC는 매번 최신 금리를 반영하여 계산한다.**
동일 기업이라도 분석 시점이 다르면 WACC가 달라지는 것이 정상.
과거 분석과의 일치를 억지로 추구하지 않는다.

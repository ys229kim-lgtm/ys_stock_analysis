# 업종 태그별 밸류에이션 가중치 기준표

## 가중치 구조
```
dcf_rim   : DCF + RIM 그룹 합산 가중치
relative  : PER + PBR + PSR + EV/EBITDA 그룹 합산 가중치
ddm       : DDM 가중치 (조건 미충족 시 dcf_rim/relative에 50:50 재배분)
```

## 가중치 선택 원칙

1. **industry_tag는 industry-analysis-agent 결과를 그대로 상속.**
   - 태그가 없으면 아래 기본 가중치 적용: `dcf_rim: 0.40, relative: 0.45, ddm: 0.15`

2. **태그 선택 판단 기준:**
   - 매출 성장률 > 20% YoY → 성장주 태그
   - 배당성향 > 50% → ddm 가중치 확대
   - 순손실 기업 → dcf_rim 가중치 확대 (FCF 가시성 중요)
   - 사이클 산업 + 업황 바닥 → relative 가중치 확대 (PBR 중심)

3. **조정 폭:** 기준표 ±0.10 이내에서 에이전트가 재량 조정 가능.
   반드시 `weight_rationale`에 조정 이유 기록.

4. **DDM 미적용 시 재배분 규칙:**
   - ddm 가중치 절반 → dcf_rim에 추가
   - ddm 가중치 절반 → relative에 추가

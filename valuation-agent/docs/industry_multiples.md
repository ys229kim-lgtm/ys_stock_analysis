## 수집 우선순위

1. **FnGuide / KisValue 업종 평균** (국내 기관 데이터)
2. **네이버 금융 업종 비교** (비교적 최신)
3. **Bloomberg / 분기 이후 공시 기반 계산** (정밀)
4. **이 파일 기본값** (최후 fallback)

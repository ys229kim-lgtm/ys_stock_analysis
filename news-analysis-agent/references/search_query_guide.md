# 검색 쿼리 조합 가이드

검색 도구 호출 시 쿼리 구성 기준.
검색 도구는 기본 Firecrawl(`mcp__firecrawl-mcp__firecrawl_search`)을 쓰되,
Firecrawl 무료 사용량/크레딧 초과 시 내장 `WebSearch`로 전환한다(CLAUDE.md Step 1 도구 정책 참조).
아래 쿼리 템플릿은 두 도구에 동일하게 적용된다.

---

## 기본 원칙

1. **연도 명시**: 쿼리에 수집 연도를 명시하여 기간 필터 효과 (예: `2024 2025`)
2. **기업명 우선**: 기업명이 쿼리 앞에 위치
3. **사건성 키워드**: 사건 유형별 키워드를 조합하여 커버리지 확대
4. **중복 최소화**: 쿼리 간 키워드 중복 최소화

---

## 국내 쿼리 (필수 실행)

| 쿼리 유형 | 쿼리 템플릿 | 목적 |
|----------|-----------|------|
| 국내 기본 | `{기업명} 뉴스 {연도1} {연도2}` | 일반 최신 뉴스 |
| 국내 사건 | `{기업명} 소송 계약 실적 제재 {연도1} {연도2}` | 사건성 기사 집중 수집 |
| 국내 전략 | `{기업명} 투자계획 신사업 로드맵 M&A {연도1} {연도2}` | 미래 계획 관련 기사 |

**연도 설정:** 현재 연도와 직전 연도를 사용.  
예: 2026년 실행 시 → `2025 2026`

---

## 해외 쿼리 (영문명 제공 시에만 실행)

| 쿼리 유형 | 쿼리 템플릿 | 목적 |
|----------|-----------|------|
| 해외 기본 | `{영문명} news {연도1} {연도2}` | 해외 보도 현황 확인 |
| 해외 사건 | `{영문명} lawsuit contract earnings penalty {연도1} {연도2}` | 해외 사건 기사 |
| 해외 전략 | `{영문명} investment strategy roadmap acquisition {연도1} {연도2}` | 해외 전략 보도 |

**해외 뉴스 정책:** 0건이어도 오류 아님. 스니펫 수준만 수집돼도 진행.

---

## 기업별 쿼리 변형

`keyword_variants.md` 참조. 기업 약칭·브랜드명·계열사명 등을 추가 쿼리에 활용.

---

## 쿼리 재시도 가이드

| 상황 | 대응 |
|------|------|
| 국내 기본 쿼리 결과 5건 미만 | 기업 약칭·계열사명으로 재시도 |
| 특정 사건 유형 누락 의심 | 해당 유형 키워드만 집중한 별도 쿼리 추가 |
| 전체 수집 20건 미만 | 수집 기간 연장 후 재시도 (최대 2년) |

## search 호출 예시

**기본 (Firecrawl):**
```
mcp__firecrawl-mcp__firecrawl_search:
  query: "삼성전자 소송 계약 실적 제재 2024 2025"
  limit: 10
```

**Fallback (사용량 초과 시, 내장 WebSearch):**
```
WebSearch:
  query: "삼성전자 소송 계약 실적 제재 2024 2025"
```

결과에서 추출 항목 (두 도구 공통, 필드명만 상이):
- 기사 제목 (`title`)
- 기사 URL (`url`)
- 요약문 (`description` / `snippet`)
- 발행일 (`publishedDate` 등 날짜 필드)
- 언론사명 (`source` 또는 도메인에서 추출)

> WebSearch는 제목·URL·스니펫 위주로 반환한다. 본문 전문이 필요하면
> 각 URL을 `mcp__crawl4ai-mcp__scrape`로 추출한다(CLAUDE.md Step 1 도구 정책 참조).

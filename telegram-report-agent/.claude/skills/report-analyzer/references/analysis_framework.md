# 종합 분석 프레임워크 (Step 5)

## 입력

`output/analysis_{날짜}_{기업명}.json` — Step 4에서 누적된 리포트별 분석 배열

전처리:
- `irrelevant: true` 리포트 제외
- `parse_failed: true` 리포트 제외
- 유효 리포트 수 계산

---

## 출력 구조 (8개 섹션)

---

### 섹션 1: 수집 개요

작성 항목:
- 총 수집 리포트 수, 유효 분석 건수, 제외 건수 (irrelevant + parse_failed)
- 분석 기간 범위 (가장 오래된 ~ 가장 최근 리포트 날짜)
- 참여 증권사 목록 및 각 사별 리포트 수 (표 형식)

---

### 섹션 2: 투자의견 분포 분석

작성 항목:
- Buy / Hold / Sell / 명시없음 건수 및 비율 (표 형식)
- 목표주가 범위: 최소값, 최대값, 평균값 (null 제외 후 계산)
- 시계열 추이: 최근 6개월 분석 기간 vs 그 이전 분석 기간 의견 방향 비교
  - 데이터가 충분하지 않으면 "데이터 부족으로 추이 분석 불가" 명시

---

### 섹션 3: 긍정 논거 통합 (Bullish Case)

작성 항목:
- 공통적으로 언급된 긍정 포인트 (언급 빈도 포함, 빈도순 정렬)
- 증권사별 차별화된 긍정 시각 (특정 증권사만 언급한 포인트)
- 핵심 촉매(Catalyst) 목록 (key_catalysts 필드 집계)

형식:
- 각 포인트 옆에 `[N개 증권사]` 또는 `[증권사명, 날짜]` 형태로 출처 명시

---

### 섹션 4: 부정 논거 통합 (Bearish Case)

작성 항목:
- 공통적으로 언급된 부정 포인트 (언급 빈도 포함, 빈도순 정렬)
- 증권사별 차별화된 우려 시각
- 핵심 리스크 목록 (risk_factors 필드 집계)

형식:
- 섹션 3과 동일하게 출처 명시

---

### 섹션 5: 실적 전망 컨센서스

작성 항목:
- 매출 추정치 범위 (최소~최대~평균, 단위 통일)
- 영업이익 추정치 범위 (최소~최대~평균)
- EPS 추정치 범위 (최소~최대~평균)
- 가장 낙관적인 증권사 vs 가장 보수적인 증권사 비교 (기준: 영업이익)
- 추정치 분산 수준 평가: "의견 수렴" (범위 좁음) / "의견 분산" (범위 넓음) / "데이터 부족"

단위 처리:
- 억원/조원 혼재 시 조원으로 통일하거나 원본 단위 유지 후 환산값 병기

---

### 섹션 6: Best Case 시나리오

작성 항목:
1. **전제 조건**: 어떤 긍정 요인이 동시에 실현되어야 하는가 (섹션 3 데이터 기반)
2. **기대 주가 범위**: 수집된 목표주가 중 상위 25% 구간 또는 최고 목표주가 (출처 명시)
3. **기대 실적 범위**: 가장 낙관적인 추정치 기준 (출처 증권사 + 날짜 명시)
4. **실현 가능성 평가**: 전제 조건의 현실성에 대한 에이전트 평가 (근거 기반)

금지:
- 수집 데이터에 없는 목표주가/실적 수치 생성 금지
- "실현될 것이다"와 같은 단언 금지 → "~될 경우 기대된다" 형태로 서술

---

### 섹션 7: Worst Case 시나리오

작성 항목:
1. **전제 조건**: 어떤 리스크 요인이 동시에 현실화되어야 하는가 (섹션 4 데이터 기반)
2. **예상 주가 범위**: 수집된 목표주가 중 하위 25% 구간 또는 최저 목표주가 (출처 명시)
3. **예상 실적 범위**: 가장 보수적인 추정치 기준 (출처 명시)
4. **현실화 가능성 평가**: 리스크 현실화 조건의 현실성에 대한 에이전트 평가

---

### 섹션 8: 종합 시각 요약

작성 항목:
- 증권가 전반 온도: **매우 긍정 / 긍정 / 중립 / 부정 / 매우 부정** 중 1개 선택 (근거 명시)
- 의견 수렴도 (컨센서스 강도): Buy 비율, 목표주가 표준편차 기반 서술
- 가장 최근 리포트 기준 방향성 변화 여부 (최근 3개월 vs 이전 의견 비교)
- 한 줄 요약: 핵심 논거를 1~2문장으로 압축

---

## 자기 검증 체크리스트

분석 완료 후 아래 항목을 점검하고, 실패 시 해당 섹션 재작성 최대 1회:

- [ ] 섹션 1~8 모두 서술 존재 (빈 섹션 금지)
- [ ] 섹션 6 (Best Case): 전제조건 + 주가범위 + 실적범위 3요소 모두 존재
- [ ] 섹션 7 (Worst Case): 전제조건 + 주가범위 + 실적범위 3요소 모두 존재
- [ ] 수치 인용 시 출처(날짜 + 증권사) 명시
- [ ] 근거 없는 전망 없음 (수집 데이터 외 수치 사용 금지)
- [ ] 유효 리포트 수 < 3건 → 섹션 1 첫머리에 경고 문구 삽입 확인
